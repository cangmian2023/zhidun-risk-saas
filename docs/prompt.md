## 信息核验模块的页面关系

```
信息核验模块
├── 信息核验列表页（首页）
│   └── 展示所有申请的核验结果
│
├── 信息核验报告详情页
│   └── 展示单个申请的完整核验结果
│       ├── 综合风险评分模型（异常值、风险等级、维度表格）
│       ├── 系统结果与工单状态
│       ├── 核验过程进度条（9步）
│       ├── 用户基本信息
│       ├── 用户证件照
│       ├── 多源并行核验单项报告（5项卡片）
│       ├── 数据交叉融合综合报告（疑点明细）
│       └── 单项核验全量操作日志
│
├── 核验规则配置页 ←── 你提到的页面
│   └── 配置"多源并行核验单项报告"中5项核验的规则

│       ├── 银行卡四要素核验规则

│       ├── 终端设备风险库核验规则

        ├── 各分段显示/隐藏
        ├── 字段显示/隐藏
        ├── 样式主题
        └── 导出模板
```

## 核验规则配置页 vs 报告模板配置页

| 对比维度 | 核验规则配置页 | 报告模板配置页 |
|----------|---------------|---------------|
| **配置对象** | 核验规则（第7步：多源并行核验） | 报告展示模板（报告详情页） |
| **配置内容** | 规则开关、阈值、权重、接口参数 | 分段顺序、字段显示、样式、导出格式 |
| **影响范围** | 核验结果（通过/预警/拒绝） | 报告展示样式 |
| **使用人员** | 技术人员、风控管理员 | 业务人员、风控主管 |
| **示例配置** | 手机号入网时长<30天=预警 | 是否显示"环境采集"分段 |

---

## 为什么不能只用核验规则配置页？

| 问题 | 说明 |
|------|------|
| **功能不同** | 核验规则配置的是"算出什么结果"，报告模板配置的是"怎么展示结果" |
| **使用人员不同** | 核验规则是技术配置，报告模板是业务配置 |
| **灵活性需求** | 不同客户需要不同的报告展示方式（字段多少、顺序、样式） |
| **权限隔离** | 业务人员不应修改核验规则，但可以调整报告模板 |

## 建议的页面拆分

### 核验规则配置页（已有）

配置**核验逻辑**：

| 核验项 | 可配置内容 |
|--------|-----------|
| 公安实名身份核验 | 三要素阈值、人脸相似度阈值、接口超时时间 |
| 银行卡四要素核验 | 卡类型限制、开户行白名单、验证次数限制 |
| 运营商手机号实名核验 | 入网时长阈值、运营商范围、在网状态要求 |
| 终端设备风险库核验 | 设备关联身份数阈值、时间窗口、风险标签 |
| 跨行业联防联控交叉核验 | 命中规则、逾期天数阈值、关联深度 |

### 报告模板配置页（新增）

配置**报告展示**：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 报告分段 | 选择显示哪些分段 | 勾选/取消"环境采集" |
| 分段顺序 | 调整分段展示顺序 | 把"操作日志"放到前面 |
| 字段显示 | 选择显示哪些字段 | 隐藏"设备指纹"字段 |
| 样式主题 | 选择报告颜色主题 | 蓝色/绿色/深色模式 |
| 导出模板 | 配置导出格式 | PDF/Word/Excel |
| 风险标签 | 配置风险标签展示 | 显示/隐藏"低风险"标签 |

# 需求17 白话版（修订版）：六大能力缺口，按"归属"分类落地

> 本文是给业务 / 产品同学看的大白话版，全程不出现代码。
> 原版按"六大缺口"平铺六段；本次按**三条归类原则**重排，便于分批落地：
> 1. **涉及模型的**——统一收口，等「模型基础系统」建成时一次性实现，不在各业务页面零散做。
> 2. **涉及策略的**（A-B / 冠军挑战者 / 版本快照 / 回测 / 灰度）——策略是规则中心 / 决策引擎的核心能力，挪到「规则 / 策略中心」系统建设时一并改，不散落各页、也不另起独立新页。
> 3. **其余的**——页面**已建**的，直接改；页面**未建**的，只记录、先不实现。

## 一、统一记录 · 待「模型基础系统」实现（模型相关）

> 这些全部围绕"模型"（动态欺诈模型、模型可解释性、模型版本管理）。底层数据已有，但展示与解释能力应统一在模型基础系统里做，避免每个页面各做一套。
> **当前状态：仅记录，不零散落地。**

### A. 模型可解释性（原缺口 5，整体收口）
想解决啥：客户被拒 / 评了多少分，要知道"哪几个因素把分推高 / 拉低"，现在只有数字列表没有直观图。
- 评分详情页：加「特征贡献瀑布图」（基线分 → 各因子加减 → 最终分）
- 评分详情页：加「拒绝归因卡」——为什么拒，关键因子红字排序
- 单客详情页"模型评分"板块：三个模型各自的因子贡献都做成可解释
- 评分查询页：加「特征归因」标签页
- 决策报告页：加「评分解释」段，一句话说清哪些因子推高 / 拉低

### B. 动态欺诈模型命中展示（原缺口 2 的模型部分）
想解决啥：客户有没有被动态欺诈模型命中，数据有但散着没集中看。
- 进件审核页设备区块：动态模型命中规则列表
- 规则中心页"设备风险"规则组：动态模型命中明细（模型名 / 命中分 / 触发特征）
- 贷中监控大盘：模型命中实时看板

### C. 模型版本管理（原缺口 4 的模型部分）
- 模型列表页：加版本管理（版本号 / 稳定性指标 / 一键回退）

## 二、归属规则 / 策略中心 · 移至彼处再改（策略相关）

> 策略（版本快照、A-B、冠军挑战者、离线回测、灰度发布）是规则中心 / 决策引擎的主能力，不是某业务页的附属。统一在「规则 / 策略中心」系统建设时做；规则中心页（规则合集）已存在，策略实验室应作为其扩展子模块，**不新建独立页面**。
> **当前状态：记录归属，待规则 / 策略中心建设时改。**

### 策略实验室相关（原缺口 4）
想解决啥：想知道"新策略比老策略效果好不好"，需要版本管理与 A/B 对比。
- 业务流程配置页：每个流程图加版本快照，能切换 / 对比不同版本（改动节点高亮）
- 策略实验室（作为规则 / 策略中心子模块，不独立建页）：同一场景新旧两策略并行跑，对比命中率 / 误杀率 / 收益
- 离线回测：拿历史客户跑策略，输出效果指标（区分度 / 提升度等）
- 灰度发布：策略按 10% 流量灰度，实时监控对比

## 三、现有页面改造 · 可直接落地（非模型 / 非策略）

> 以下均不涉及模型、不涉及策略，且目标页面都**已建**，可以现在直接改。

### 1. 跨行业联防联控（原缺口 1）
想解决啥：一个客户是不是同时在多家机构借钱 / 跟老赖共用设备，现在只一句话"命中"，看不出关系网。
- **单客详情页**：关系图谱加「名单网络」视图——客户、借款机构、黑名单库连成网，常一起出现的机构自动高亮
- **单客详情页**：加「多头共债」小板块——近 30 天在几家机构申请、跟谁共债、同设备申请几次
- **规则中心页**：加「跨机构名单网络」标签页，矩阵展示"各机构 × 各名单类型"的命中数 / 命中率
- **进件审核页**：命中联防联控从一句话升级成「命中机构清单 + 共债链条」卡片
- **贷中监控大盘**：加「共债网络 TOP」排行榜

### 2. 设备维度（原缺口 2 的设备部分，不含动态模型）
想解决啥：客户设备干不干净（模拟器 / 群控 / 越狱），数据有但没集中看。
- **单客详情页**：加「设备与欺诈维度」板块（设备号 / 机型 / 系统 / 环境风险分 / 是否模拟器）
- **单客详情关系图谱**：加「设备」节点类型，画出"同设备多账号"关系
- **进件审核页**：设备区块升级成「设备风险画像」（指纹一致性 + 环境分，不含动态模型部分）
- **规则中心页**：「设备风险」规则组已建，补足命中明细展示
- **贷中监控大盘**：加「高危设备 / 模拟器」实时看板（设备部分）

### 3. 周期性监测引擎（原缺口 3）
想解决啥：周期性扫描任务看不到"上次扫没、下次啥时扫、扫出多少命中"，也没有"扫到就告警"。
- **持续性周期监测页（cr:mid-td4）**：加「运行态」标签页——上次扫描 / 下次扫描 / 命中数 / 成功率 / 耗时
- **持续性周期监测页**：加「试运行」按钮，模拟扫一次看命中预览
- **贷中监控大盘**：加「引擎运行态势」卡片（运行中任务数 / 今日扫描客户数 / 今日命中数）
- **预警工作台**：命中即告警，自动生成预警 + 处置工单
- **预警工作台**：加流式命中信息流（实时视图）

### 4. 分群运营深化（原缺口 6）
想解决啥：对存量客户做促活 / 提额 / 二次经营，看不到"名单从候选到落地"的跟踪。
- **存量客群运营页（cr:mid-td5）**：加「运营名单跟踪」标签页（客户 / 分层 / 动作 / 评估状态 / 最近评估日 / 下次评估日）
- **存量客群运营页**：名单按月 / 季自动复评，状态走"候选 → 评估中 → 已提额 / 已促活"
- **存量客群运营页**：加「促活 / 提额效果看板」（转化率 / 金额 / 留存）
- **单客详情页**：加「运营动作」时间线，看历次提额 / 促活记录
- **首页**：加「运营机会」卡片，一键直达名单跟踪

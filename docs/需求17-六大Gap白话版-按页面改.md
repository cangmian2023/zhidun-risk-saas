# 需求17 白话版：六大风控能力缺口，怎么在现有页面里补上

> 这是给业务 / 产品同学看的大白话版。原技术文档（含开发代码落点）保留在《需求17-六大Gap可实现性与优化方案》里，供开发参考。
> 本文只回答两件事：**每个能力缺什么**、**具体在哪些页面加什么东西**（全程不出现代码）。

## 一句话总览
这六大块，平台底层的数据和组件其实都已经有了一部分，只是"没把能力展示出来 / 没串成闭环"。结论很乐观——**全部可以在现有页面里改出来，不用新建一套系统**。改法都只是：在某个页面加个板块、加个标签页，或者把已有的数据换个方式呈现。

## 总览
| # | 能力缺口 | 能不能在现有页面改 | 改动大小 | 主要涉及页面 |
|---|---|---|---|---|
| 1 | 跨行业联防联控（多头 / 共债网络） | 能 | 中等 | 单客详情页、规则中心页、进件审核页、贷中监控大盘 |
| 2 | 设备指纹 / 动态欺诈模型 | 能 | 中等 | 单客详情页、进件审核页、规则中心页、贷中监控大盘 |
| 3 | 周期性监测引擎（运行态闭环） | 能 | 中等 | 周期监测配置页、贷中监控大盘 |

## 1. 跨行业联防联控：缺"多头借贷 / 共债"的实时关系网络视图

**它想解决啥**：一个客户是不是同时在好几家机构借钱？是不是跟一群老赖共用同一台设备、同一个联系人？现在平台只用一句话告诉你"命中 / 没命中"，看不出背后的关系网。

**哪些页面怎么改（5 处）**：
- **单客详情页**：关系图谱加一个"名单网络"视图——把客户、借款机构、黑名单库连成一张网，经常一起出现的机构自动高亮。
- **规则中心页**：新增"跨机构名单网络"标签页，用矩阵展示"各机构 × 各名单类型"的命中数和命中率。
- **单客详情页**：加一个"多头共债"小板块，显示"近 30 天在几家机构申请、跟谁共债、同设备申请了几次"。
- **进件审核页**：把"命中联防联控"从一句话，升级成"命中机构清单 + 共债链条"卡片。
- **贷中监控大盘**：加一个"共债网络 TOP"排行榜。

---

## 2. 设备指纹 / 动态欺诈模型：缺设备维度与动态模型命中展示

**它想解决啥**：客户用的手机 / 设备干不干净——是不是模拟器、群控、越狱机？有没有被动态欺诈模型命中？数据平台其实都有，但散在各处，没有集中看的地方。

**哪些页面怎么改（5 处）**：
- **单客详情页**：加"设备与欺诈维度"板块（设备号 / 机型 / 系统 / 环境风险分 / 是否模拟器）。
- **进件审核页**：设备区块升级成"设备风险画像"（指纹一致性 + 环境分 + 动态模型命中规则列表）。
- **规则中心页**：加"设备风险"规则组，列出动态模型命中明细（模型名 / 命中分 / 触发特征）。
- **单客详情关系图谱**：加"设备"节点类型，把"同设备多账号"关系画出来。
- **贷中监控大盘**：加"高危设备 / 模拟器"实时看板。

---

## 3. 周期性监测引擎：让扫描任务"活"起来、扫到就告警

**它想解决啥**：平台有一堆"每月扫一次睡眠客户"之类的周期性任务，但现在看不到"上次扫了没、下次啥时候扫、扫出多少命中"，也没有"扫到风险就自动告警"。

**哪些页面怎么改（5 处）**：
- **周期监测配置页**：加"运行态"标签页，每个任务显示"上次扫描 / 下次扫描 / 命中数 / 成功率 / 耗时"。
- **命中即告警**：任务扫到风险，自动生成预警 + 处置工单。
- **贷中监控大盘**：加"引擎运行态势"卡片（运行中任务数 / 今日扫描客户数 / 今日命中数）。
- **周期监测配置页**：加"试运行"按钮，模拟扫一次看命中预览。
- **实时监控任务**：加一个流式命中信息流（类似预警工作台的实时视图）。

---

## 4. 策略实验室 / A-B / 冠军挑战者：哪版策略更好

**它想解决啥**：想知道"新策略比老策略效果好不好"，需要版本管理和 A/B 对比。目前平台只在文档里提过，没真功能。

**哪些页面怎么改（这个最重，需要新建一个轻量页面）**：
- **业务流程配置页**：每个流程图加版本快照，能切换 / 对比不同版本（改动的节点高亮）。
- **新增"策略实验室"页面**：同一场景下新旧两个策略并行跑，对比命中率 / 误杀率 / 收益。
- **模型列表页**：加版本管理（版本号 / 稳定性指标 / 一键回退）。
- **离线回测**：拿历史客户跑策略，输出效果指标（区分度 / 提升度等）。
- **灰度发布**：策略按 10% 流量灰度，实时监控对比。

---

## 5. 模型可解释性：为什么拒我 / 分是怎么算出来的

**它想解决啥**：客户被拒、或评了多少分，得知道"到底是哪几个因素把分推高 / 拉低的"。现在只有因子贡献的数字列表，没有直观图。

**哪些页面怎么改（最轻，只加图，5 处）**：
- **评分详情页**：加"特征贡献瀑布图"（基线分 → 各因子加减 → 最终分）。
- **评分详情页**：加"拒绝归因卡"——为什么拒，关键因子红字排序。
- **单客详情页"模型评分"板块**：把三个模型各自的因子贡献都做成可解释。
- **评分查询页**：加"特征归因"标签页。
- **决策报告页**：加"评分解释"段，一句话说清哪些因子推高 / 拉低。

---

## 6. 分群运营深化：促活 / 提额 / 二次经营名单的跟踪

**它想解决啥**：对存量客户做促活、提额、二次经营，但现在看不到"名单从候选到落地"的跟踪过程。

**哪些页面怎么改（5 处）**：
- **存量客群运营页**：加"运营名单跟踪"标签页（客户 / 分层 / 动作 / 评估状态 / 最近评估日 / 下次评估日）。
- **存量客群运营页**：名单按月 / 季自动复评，状态走"候选 → 评估中 → 已提额 / 已促活"。
- **存量客群运营页**：加"促活 / 提额效果看板"（转化率 / 金额 / 留存）。
- **单客详情页**：加"运营动作"时间线，看这个客户历次提额 / 促活记录。
- **首页**：加"运营机会"卡片，一键直达名单跟踪。

---

## 先做哪个（优先级）

- **先做（成本低、改完立刻有感觉）**：第 5 条 瀑布图（只加张图）、第 3 条 监测运行态标签（数据已有）、第 1 条 联防联控网络图（复用关系图谱）。
- **中期**：第 2 条 设备维度板块、第 6 条 运营名单跟踪标签。
- **最后（唯一要新建页面的）**：第 4 条 策略实验室。

> 所有方案都不新建数据通道，只是在现有页面把已有的数据 / 组件重新组织、展示出来。

# 零售信贷子系统 · 需求满足度评审与竞品规划

> 文档目标（需求13）：以"最初需求"为基准，评审当前零售信贷子系统（贷前审核 / 贷中监控）的满足情况，总结未被满足的需求；调研同赛道竞品如何满足这些需求；结合竞品分析给出功能规划。本文为**文档层面讨论**，不涉及代码改动。

---

## 0. 评审基线说明

- **对照基准**：用户给出的"最初需求"——贷前审核 4 项功能（信息核验 / 信用风控 / 欺诈识别 / 决策报告）+ 贷中监控 5 项功能（持续性周期监测评估 / 分场景分产品监测 / 红黄灯综合预警信号 / 模块化灵活定制 / 多方式获取结果）。
- **满足度分级**：
  - ✅ 已实现：有可用页面 + 交互 + 样例数据闭环，可演示。
  - 🟡 部分实现：有入口/配置项，但核心引擎或真实数据通道为 mock。
  - ❌ 未实现：仅有 spec 展示页（specsCr.ts）或完全缺失。
- **架构约束**：本项目所有页面数据来自本地样例 JSON（需求12明确架构）。因此"实现"指 UI+交互+样例数据闭环；跨机构实时数据、真实 API 推送等后端能力按 demo 架构本就不接入，评审判定时不做苛求，但会把"真实通道缺失"列为待补演示缺口。

## 1. 当前子系统结构（代码实测）

**贷前审核（section: 贷前审核）**
- 进件审核 `cr:pre-report` → 整合信息核验+信用风控+欺诈识别的综合报告 + 决策建议（`PreApplication.tsx` 决策引擎跑批、报告生成/导出）。
- 信息核验 `cr:pre-verify` → `InfoVerify222.tsx` + Detail。
- 信用风控 `cr:credit-kimi` → `CreditVerify222.tsx`。
- 欺诈识别 `cr:pre-fraud` → `FraudVerify222.tsx` + 单客详情关系图谱团伙识别。

**贷中监控（section: 贷中监控）**
- 监控看板组：贷中监控大盘 `cr:mid-td1`（红黄灯总览）、风险监测 `cr:mid-td2`（分场景分产品）、红黄灯预警中心 `cr:mid-td3`、持续性周期监测 `cr:mid-td4`、存量客群运营 `cr:mid-td5`——均来自 `midDashboards.json` 配置驱动渲染。
- 预警处置组：预警工作台 `cr:mid-alert-workbench`、处置工单 `cr:mid-dispose-workbench`、单客视图 `cr:mid-cust-detail`。
- 配置侧（cm）：数据源管理、指标库、监控任务、处置策略、页面配置、业务流程配置。

## 3. 未被满足的需求总结（Gap）

1. **多方式获取结果**：API 推送 / URL 回调 / SFTP 文件交换 / 网页下载——目前仅停留在配置标签与 spec 列表，没有可见的"投递任务 / 下载入口 / 推送记录"。
2. **跨行业联防联控**：信用风控中的"跨机构风险名单网络"为样例名单，缺真实多头/共债实时网络视图（同盾、百融的核心卖点）。
3. **设备指纹 / 动态欺诈模型**：欺诈识别仍停留在关系网络层面，缺设备维度（设备ID、环境、风险分）与动态模型命中展示。
4. **周期性监测引擎**：扫描频次可配，但缺"扫描引擎运行态（上次/下次扫描、命中数）+ 命中即告警"的闭环展示（邦盛流立方、顶象实时指标的思路）。
5. **策略实验室 / A-B / 冠军挑战者**：缺策略版本管理与效果对比能力（顶象 Dinsight 的核心差异点）。
6. **模型可解释性**：决策报告/评分的"特征贡献 / 为什么是这个分"展示较浅，缺 waterfall、特征归因（蚁盾建模 Agent、FICO 的强项）。
7. **分群运营深化**：存量客群运营(td5)有雏形，但"促活/提额/二次经营"的周期性评估与名单跟踪链路偏弱（腾讯天御分群运营的强项）。

## 4. 竞品如何满足这些需求

### 4.1 对标厂商与核心能力

| 厂商 | 定位 | 与本次 Gap 相关的关键能力 |
|---|---|---|
| **同盾科技** | 信贷风控资深玩家 | 贷前审核四件套（信息核验/信用/欺诈/决策报告）；**云图知识图谱**（团伙/关联/风险传播）；**智信分**评分卡；**跨机构风险名单网络**（联防联控、多头借贷）；决策引擎；**"报告+报文"双输出** |
| **顶象 Dinsight** | 实时风控引擎 | **设备指纹** + 流计算毫秒级决策；**可视化策略管理**（规则引擎/决策流/版本管理/**冠军挑战者**）；**策略实验室**（线上/历史/自定义数据调优对比）；智能风险监控大盘；贷前准入/贷中监控/贷后全链路 |
| **腾讯天御** | 全生命周期智能风控 | 覆盖"获客-准入-维护"；设备安全+图灵盾；**TenDI 决策平台**；**联邦学习（数据可用不可见）**；反电诈引擎；**分群运营（促活/提额/二次经营）**；光大银行三层架构（数据层融合 / 个体+团伙双引擎 GNN / 运营闭环） |
| **蚂蚁蚁盾** | 全流程智能风控 | **智能风控建模 Agent**（自然语言交互建模）；蚁盾决策引擎；流量/贷前/贷中/贷后全流程；统一风控平台（13+场景） |
| **百融云创** | 持牌征信+评分 | 信用评分卡（消费金融市占率高）；**多头借贷检测**；决策引擎（多数据源并行） |
| **邦盛科技** | 实时风控 | "流立方"毫秒级实时计算；交易/授信实时反欺诈 |
| **冰鉴科技** | 小微风控 | 机器学习建模、信用评估、反欺诈 |
| 通用底座 | — | 设备指纹（同盾/顶象/数美/易盾）、知识图谱（同盾云图/腾讯）、联邦学习（天御/同盾）、决策引擎（同盾/蚁盾/百融/FICO/SAS）、策略实验室（顶象） |

### 4.2 各 Gap 的竞品解法映射

- **多方式获取结果** → 同盾"报告+报文"、腾讯"推送/订阅"、顶象"API/SDK"。竞品共性：把"结果投递"做成独立可配置通道，并留存投递/订阅记录。
- **跨行业联防联控** → 同盾风险名单网络、百融多头检测、腾讯联邦学习。竞品共性：以"风险名单网络 + 跨主体数据对齐"识别多头/共债。
- **设备指纹 / 动态模型** → 顶象/同盾/数美设备指纹。竞品共性：设备维度风险分 + 异常设备行为序列。
- **周期性监测引擎** → 邦盛流立方、顶象实时指标计算。竞品共性：实时/准实时指标聚合 + 命中即告警 + 运行态可观测。
- **策略实验室 / A-B** → 顶象策略实验室。竞品共性：策略版本 + 冠军挑战者 + 新老策略效果对比。
- **模型可解释** → 蚁盾建模 Agent、FICO。竞品共性：特征贡献归因、可解释报告。
- **分群运营** → 腾讯天御分群运营。竞品共性：按风险+价值分层输出促活/提额/二次经营名单并跟踪效果。

## 5. 基于竞品分析的功能规划

> 规划原则：在"本地样例 JSON"架构内，用样例数据把竞品的差异化能力"演示出来"，形成可点击、可解释的闭环，而非接真实后端。

### P0 · 补全闭环演示（优先级最高）
1. **结果投递中心（多方式获取结果）**：在监控任务/看板配置中，把 `OUTPUT_LABEL`(api/url/file/web) 落成可见的"投递任务"样例——API 回调记录、SFTP 批次清单、网页下载按钮、看板订阅。让"多方式获取结果"从配置项变成**可见的投递记录 + 下载入口**（借鉴同盾报文 + 顶象 SDK）。
2. **跨机构风险名单网络（联防联控）**：新增"风险名单网络"样例页——名单库（样例名单 + 命中类型）+ 客户命中展示 + 多头/共债提示（借鉴同盾名单网络 + 百融多头检测）。

### P1 · 增强真实感
3. **设备维度与欺诈识别**：设备指纹样例卡（设备ID/环境/风险分/异常行为序列）+ 动态模型命中（借鉴顶象/同盾设备指纹）。
4. **周期性监测引擎状态**：扫描引擎运行态（上次扫描/下次扫描/命中数/扫描耗时）+ 命中即告警闭环（借鉴邦盛流立方/顶象实时指标）。
5. **策略实验室**：策略版本 + 冠军挑战者样例 + 新老策略命中对比（借鉴顶象策略实验室）。

### P2 · 智能化
6. **模型可解释性**：评分/决策报告的"特征贡献 waterfall + 关键驱动因子"展示（借鉴蚁盾建模 Agent / FICO）。
7. **联邦学习示意（数据可用不可见）**：跨主体数据对齐的合规协作示意页（借鉴腾讯天御联邦学习）。
8. **分群运营深化**：促活/提额/二次经营名单的周期性评估与效果跟踪链路（借鉴天御分群运营）。

## 6. 文档层面待确认事项（讨论点）

- **需求12「底层架构」的具体约定**：三色标签（🟠样例/🔵配置/⚪计算）、本地样例 JSON、DetailHeader/PageHeader 模板化、业务流程配置、看板配置——这些约定在 `MidAlertDetail` / `MidCustDetail` 上的落地程度需先对账，再谈"重构满足架构"。

- **需求16 菜单优化**：升级后的 5 个看板页（大盘/风险监测/红黄灯中心/周期监测/存量客群运营）在删除"监控看板""预警处置"两个 group 头后如何归组；"处置工单""单客视图"删除后，其能力（工单回填、客户360）需归并到预警工作台 / 预警详情页，避免能力丢失。

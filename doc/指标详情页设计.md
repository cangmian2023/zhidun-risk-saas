# 指标详情页设计（贷中监控 · 指标库）

> 依据 0805.md 第 5 项（5.1~5.4）编写，承接第 4 项「先设计文档再实现」的约定。
> 指标库属管理中心配置域（配置 JSON = 蓝）；样例行来自数据源（橘），实时值由公式计算（灰）。

## 1. 目标与边界
- 详情页展示单条指标的配置口径、关联数据源、被引用情况；实时值由样例数据（橘）经公式（灰）驱动。
- **功能页面与样例数据分离**：页面不写死数值，只标注来源位置，值从 `midMetrics.json` / 数据源 `rows` 实时读取。

## 2. 指标状态模型（5.2 核心）
指标有两个正交维度，组合出 4 种状态：

| 类型 \ 启用 | 启用 enabled | 停用 disabled |
|---|---|---|
| 基础指标 base | 正常采集 | 暂停采集 |
| 派生指标 derived | 正常计算 | 暂停计算 |

每种状态对应操作：
- 编辑：进编辑弹窗（字段来源选数据源 json）
- 启用/停用切换：详情页按钮，写回 `midMetrics.json`
- 查看数据源：内嵌面板 + 跳转
- 查看引用：监控规则（橙）/ 看板组件（蓝）

## 3. 数据源关联（5.3）
- 新建/编辑指标时，从「数据源列表 json」选择 `dataSourceId`；base 指标的度量字段、聚合来自该数据源字段。
- 派生指标公式可引用其它指标（`m_指标ID`）。
- **详情页内嵌「数据源」面板**：展示关联数据源的名称/类型/状态/字段清单（读 `midDataSources.json`），而非仅跳转按钮。

## 4. 详情页信息架构
1. 顶部操作条：返回 / 编辑 / 启用·停用切换 + 来源标签（`配置JSON·midMetrics.json`）
2. 信息条 InfoCell：类型、状态、分组、单位、精度、实时值（灰）
3. 面板「口径定义」：base→聚合方式/度量字段/单位/精度/分组；derived→公式/单位/精度/分组。样例驱动（橘）标注数据源 rows
4. 面板「数据源」（新增）：关联数据源详情（名称/类型/状态 + 字段清单表）
5. 面板「被引用」：监控规则（橙 Badge）、看板组件（蓝 Badge），数量 + 跳转

## 5. 列表页标签规范（5.1，对齐数据源列表）
列标签采用 `大类·具体路径`：
- 指标名称 → `配置JSON·midMetrics.json.name`
- 分组 → `配置JSON·midMetrics.json.group`
- 类型 → `配置JSON·midMetrics.json.type`
- 口径 → `配置JSON·midMetrics.json.<formula|agg+field>`
- 数据源 → `配置JSON·midMetrics.json.dataSourceId`
- 实时预览 → `实时计算`（灰）

## 6. 样例数据规范（5.4）
覆盖贷中监控 4 组，含 base+derived、enabled+disabled：

- **客群**：在贷客户数、本月新增客户数、活跃客户数、流失客户数
- **风险**：在贷余额、逾期金额、逾期率(derived)、授信额度、额度使用率(derived)、行为均分、不良金额、不良率(derived)
- **预警**：预警总数、红灯预警数、黄灯预警数、机会预警数
- **处置**：处置次数、处置率(derived)、自动处置数

派生公式引用需存在的基础指标：
- 逾期率 `m_overdue_amt / m_loan_balance * 100`
- 额度使用率 `m_loan_balance / m_credit_line * 100`
- 不良率 `m_npl_amt / m_loan_balance * 100`
- 处置率 `m_dispose_cnt / m_alert_cnt * 100`

状态分布：基础指标多数启用；派生指标多数启用；挑选 2~3 条设为 `disabled` 演示「停用」状态，列表/详情均能区分显示。

## 7. 实现落点
- 类型：`midData.ts` 的 `MidMetric` 增加 `enabled?: boolean`
- 列表：`MidMetricConfig.tsx` 列标签改具体路径（5.1），增加状态列
- 详情：`MidMetricDetail.tsx` 重写（状态徽标 + 启用切换 + 数据源面板，5.2/5.3）
- 样例：`midMetrics.json` 与 `SEED_METRICS` 同步扩充（5.4）

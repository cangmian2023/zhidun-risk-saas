- 模板 `GRADE_PRESETS.info_verify` 是**异常值**语义，越高越危险，**4 段**：0-20 安全 / 21-50 关注 / 51-80 警示 / 81-100 高危
- 详情页刻度条是**信用值**语义，越高越安全，**3 段**：<20 低信用(红) / 20-80 中(黄) / ≥80 高信用(绿)

方向相反、段数还不同，硬接会错得离谱。三条路子你挑：
- (a) 详情页改成异常值语义，完全跟模板走（改动大，但模型统一）
- (b) 模板加个"展示语义/是否反转"开关，详情页按开关渲染（灵活，但多一层概念）
- (c) 刻度条改读 `dimBands` 而不是 `grades`（`dimBands` 本来就是低/中/高三段，天然对得上）

我倾向 **(c)**，改动最小又不破坏语义。

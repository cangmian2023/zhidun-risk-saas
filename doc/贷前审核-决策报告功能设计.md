## 一、决策报告的业务定位

### 1.1 贷前审核完整流程

```
申请人提交申请
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  第一步：信息核验                                            │
│  验证身份真实性、资料完整性、格式正确性                      │
│  输出：核验结果（通过/拒绝/预警）+ 异常值                    │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  第二步：信用风控                                            │
│  评估还款能力、信用历史、行为稳定性                          │
│  输出：信用评分（0-100，越高越差）+ 信用风险等级             │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  第三步：欺诈识别                                            │
│  识别设备欺诈、身份欺诈、团伙欺诈、行为欺诈                  │
│  输出：欺诈评分（0-100，越高越差）+ 欺诈风险等级           │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  ★ 第四步：决策报告（本模块）                               │
│  整合前三步结果，综合决策，输出最终授信建议                  │
│  输出：决策建议（通过/拒绝/限制额度/转人工）+ 授信方案     │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  第五步：人工审核（如需）                                    │
│  风控人员复核决策报告，确认或修正授信方案                    │
│  输出：最终审批结果                                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
  放款 / 拒绝 / 补充材料
```

### 1.2 决策报告的核心作用

| 作用 | 说明 |
|------|------|
| **信息整合** | 将信息核验、信用风控、欺诈识别三个报告的结果汇总到一个页面 |
| **综合决策** | 基于三个报告的结果，通过决策引擎输出最终授信建议 |
| **降本增效** | 减少风控人员翻阅多个报告的时间，提升审核效率 |
| **决策留痕** | 记录决策依据、审批流程、操作日志，便于审计和回溯 |
| **策略优化** | 基于决策结果反馈，持续优化决策引擎的规则和模型 |

### 1.3 决策报告 vs 三个子报告的关系

| 对比维度 | 信息核验报告 | 信用风控报告 | 欺诈识别报告 | 决策报告 |
|----------|-------------|-------------|-------------|----------|
| **核心问题** | "信息对不对？" | "能不能还钱？" | "是不是骗子？" | **"最终给不给钱？"** |
| **评分方向** | 异常值（越高越差） | 信用评分（越高越差） | 欺诈评分（越高越差） | **决策评分（综合评估）** |
| **输出产物** | 核验结果 + 异常值 | 信用评分 + 授信建议 | 欺诈评分 + 处置建议 | **决策建议 + 授信方案** |
| **人工介入** | 核验异常时介入 | 信用风险高时介入 | 欺诈嫌疑时介入 | **综合判断后统一介入** |
| **决策权限** | 无 | 无 | 无 | **有（最终决策）** |

## 二、决策引擎设计

### 2.1 决策引擎输入

决策引擎接收三个子系统的输出作为输入：

| 输入项 | 来源 | 数据格式 | 示例 |
|--------|------|----------|------|
| 信息核验结果 | 信息核验系统 | 通过/拒绝/预警 + 异常值 | 预警，异常值58 |
| 信用评分 | 信用风控系统 | 0-100分 + 信用风险等级 | 88分，高风险 |
| 欺诈评分 | 欺诈识别系统 | 0-100分 + 欺诈风险等级 | 88分，极高风险 |
| 申请信息 | 申请系统 | 产品、额度、期限、利率 | 信用贷，3万，12期 |
| 客户画像 | 客户系统 | 新老客户、历史授信、还款记录 | 新客户，无历史 |

### 2.2 决策规则引擎

#### 规则1：一票否决（硬性规则）

| 条件 | 决策结果 | 说明 |
|------|----------|------|
| 信息核验 = 拒绝 | **拒绝** | 身份不实，直接拒绝 |
| 欺诈评分 ≥ 80（极高风险） | **拒绝** | 确认欺诈嫌疑，直接拒绝 |
| 命中黑名单 | **拒绝** | 命中黑名单，直接拒绝 |
| 命中团伙欺诈且关联度>90 | **拒绝** | 团伙欺诈，直接拒绝 |

#### 规则2：综合评分计算

```
决策评分 = 信息核验权重×信息核验得分
        + 信用风控权重× (信用评分 / 900 × 100)
        + 欺诈识别权重× (100 - 欺诈分) 

默认权重：
  信息核验：30%
  信用风控：40%
  欺诈识别：30%

```

#### 规则3：决策建议映射

|  决策评分  | 决策建议     | 授信额度         | 利率浮动        |
| :----: | :------- | :----------- | :---------- |
| 80-100 | **优先通过** | 申请额度的100%+提额 | 基准利率-5%     |
|  60-79 | **通过**   | 申请额度的100%    | 基准利率        |
|  40-59 | **限制额度** | 申请额度的50-80%  | 基准利率+5-10%  |
|  20-39 | **严格限制** | 申请额度的10-30%  | 基准利率+15-20% |
|  0-19  | **拒绝**   | --           | --          |

### 2.3 决策引擎输出

| 输出项 | 说明 | 示例 |
|--------|------|------|
| 决策编号 | 唯一标识 | DR-20260725-001 |
| 决策时间 | 决策生成时间 | 2026-07-25 15:00:22 |
| 决策评分 | 综合评分(0-100) | 72分 |
| 决策建议 | 最终授信建议 | 限制额度 |
| 建议授信额度 | 具体授信金额 | ¥15,000（申请额度的50%） |
| 建议利率 | 具体利率 | 基准利率+10% |
| 决策依据 | 触发该决策的关键规则 | 信用评分88分（高风险）+ 欺诈评分88分（极高风险） |
| 风险提示 | 需要关注的风险点 | 信用历史差、设备异常、疑似团伙关联 |
| 人工复核建议 | 是否需要人工复核 | 必须人工复核 |

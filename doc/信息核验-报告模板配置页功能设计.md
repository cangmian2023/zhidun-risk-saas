# 信息核验 — 报告模板配置页功能设计

> 本文档定义「信息核验」模块下「报告模板配置页」的产品功能设计。
> 该页面用于配置**信息核验报告详情页**（`PreVerifyDetail.tsx`）的展示模板，包括：报告分段顺序、各分段显示/隐藏、字段级显示/隐藏、样式主题、导出模板。
> 对应代码展示端：`SaaS/src/console/PreVerifyDetail.tsx`（7 个 Panel 模块 + 右侧锚点导航）。
> 设计模式参考姊妹页「核验规则配置页」（`VerifyRuleEditor.tsx`）：左侧模板列表 + 右侧配置面板，支持模板增删改。

## 一、页面定位

| 维度 | 说明 |
|------|------|
| **所属模块** | 信息核验（贷前审核） |
| **页面名称** | 报告模板配置 |
| **页面类型** | 配置型管理页（左侧模板列表 + 右侧配置面板） |
| **访问入口** | 左侧菜单「信息核验」→「报告模板」 |
| **操作权限** | 系统管理员、风控主管可编辑；风控专员仅可查看与切换模板 |

## 三、左侧模板列表

### 3.1 列表结构

左侧固定宽度边栏（260px），显示当前所有的报告模板。

| 展示项 | 说明 |
|--------|------|
| **图标** | 模板类型图标（📋 标准报告 / 🎯 专项报告 / 📊 精简报告） |
| **模板名称** | 如「标准信息核验报告模板」 |
| **状态标记** | `默认`（绿色）/`草稿`（蓝色）/`已启用`（绿色）/`已停用`（灰色） |
| **适用产品** | 全产品 / 信用贷 / 抵押贷 / 经营贷 |
| **修改信息** | 最后修改人 · 修改时间 |

### 3.2 列表交互

- **点击切换**：点击模板项，右侧加载该模板的完整配置。
- **hover 删除**：鼠标悬停显示删除按钮（仅草稿/已停用模板可删除）。
- **底部新建**：「+ 新建模板」按钮，点击后右侧进入新建模式（`?id=new`）。
- **默认模板**：默认模板项在名称旁显示绿色「默认」Badge，不可删除。

### 3.3 模板数据结构

```typescript
interface ReportTemplate {
  id: string
  name: string           // 模板名称
  scope: string[]        // 适用产品
  status: '草稿' | '已启用' | '已停用'
  isDefault: boolean     // 是否为默认模板
  description: string    // 模板描述
  lastEditor: string
  lastEditTime: string
  // 配置内容
  sections: SectionConfig[]    // 分段配置
  fieldVisibility: Record<string, boolean>  // 字段显隐
  theme: ThemeConfig     // 样式主题
  export: ExportConfig   // 导出模板
}
```

## 四、模板基础信息（右侧顶部）

选中模板后，右侧顶部显示基础信息配置区。

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|:----:|--------|------|
| **模板名称** | 文本输入 | 是 | — | 如「标准信息核验报告模板」 |
| **适用产品** | 多选下拉 | 否 | 全产品 | 该模板默认应用于哪些产品 |
| **模板描述** | 多行文本 | 否 | — | 说明模板用途与适用场景 |
| **模板状态** | 单选 | 是 | 草稿 | `草稿 / 已启用 / 已停用` |
| **设为默认模板** | 开关 | 否 | 关闭 | 开启后新进入件默认使用该模板 |

> **默认模板互斥**：仅一个模板可同时设为默认。切换默认时系统提示「切换后新进入件将使用新模板，历史报告不受影响」。

## 五、报告分段配置

### 5.1 可配置的分段列表

信息核验报告详情页共 **7 个分段**（对应 `PreVerifyDetail.tsx` 中的 7 个 `Panel`）。

| 序号 | 分段标识 | 分段名称 | 对应代码区域 | 是否可隐藏 |
|:----:|---------|---------|-------------|:---------:|
| 1 | `score_model` | 信用值模型卡 | 领衔区 1 · 信用值模型卡 | ✓ |
| 2 | `conclusion_process` | 结论与终审操作卡 + 核验过程 | 领衔区 2 · 结论卡 + 核验过程时间线 | ✓ |
| 3 | `basic_info` | 用户基本信息 | 一、用户基本信息 | ✓ |
| 4 | `id_images` | 用户证件照 | 二、用户证件照 | ✓ |
| 5 | `single_verify` | 多源并行核验单项报告 | 三、多源并行核验单项报告（5 卡） | ✓ |
| 6 | `cross_fusion` | 数据交叉融合综合报告 | 五、数据交叉融合综合报告 | ✓ |
| 7 | `op_logs` | 单项核验全量操作日志 | 六、单项核验全量操作日志 | ✓ |

### 5.2 分段顺序配置交互

- **拖拽排序**：以拖拽手柄（⋮⋮）调整分段顺序，右侧预览区实时同步刷新。
- **显示/隐藏开关**：每个分段左侧有 Checkbox，取消勾选后该分段在报告中不渲染。
- **最少保留**：系统要求至少保留 1 个分段，仅剩 1 个时 Checkbox 置灰不可取消。
- **锚点导航同步**：右侧预览区的锚点导航（`navCards`）顺序与分段顺序保持一致，隐藏的分段不生成锚点。

### 5.3 数据结构

```typescript
interface SectionConfig {
  id: string           // 分段标识
  name: string         // 分段名称
  order: number        // 排序序号
  visible: boolean     // 是否显示
  fields: FieldConfig[] // 字段配置（见第六节）
}
```

## 六、字段显示/隐藏

### 6.1 交互方式

- 点击某个分段（如「用户基本信息」），下方展开该分段的所有可配置字段列表。
- 每个字段前有 Checkbox，勾选即显示，取消即隐藏。
- 支持「全选 / 全不选」快捷操作。

## 九、实时预览机制

### 9.1 预览区位置

预览区位于右侧配置面板底部，或作为独立 Tab（「配置」/「预览」切换）。推荐采用**底部固定预览区**：

- 占右侧主区域下方 40% 高度
- 可折叠/展开（默认展开）
- 内部滚动，不影响上方配置区

### 9.2 预览数据

- 使用固定的样例数据（`infoVerifyReport.ts` 中 `buildBaseInfoVerifyReport()` 生成的三态样例）。
- 预览区顶部提供状态切换按钮：`通过(pass) / 预警(warning) / 拒绝(reject)`。
- 预览区显示「当前预览：拒绝态 | 切换：通过 预警 拒绝」。

### 9.3 预览刷新策略

- 任何配置项变更（分段顺序、字段显隐、样式颜色）在 **300ms debounce** 后触发预览区重新渲染。
- 预览区与真实报告详情页 **1:1 还原**，使用同一套 `Panel` 组件。
- 预览区不支持交互（按钮点击、弹窗展开等仅作展示，不触发实际逻辑）。

## 十、模板版本与复用

### 10.1 模板管理操作

| 功能 | 说明 |
|------|------|
| **保存** | 保存当前配置为「草稿」状态 |
| **预览** | 在新标签页打开全屏预览，使用样例数据完整渲染 |
| **设为默认** | 将该模板设为默认模板，新进入件自动应用 |
| **复制模板** | 基于当前模板创建副本，副本名称为「{原名称} - 复制」 |
| **删除** | 删除草稿/停用状态的模板；已启用的模板需先停用才可删除 |

### 10.2 模板变更日志

| 字段 | 说明 |
|------|------|
| **版本号** | 模板版本，格式 `V{major}.{minor}` |
| **操作类型** | `创建 / 编辑 / 启用 / 停用 / 复制 / 删除` |
| **操作人** | 系统用户 |
| **操作时间** | 精确到秒 |
| **变更摘要** | 自动提取变更内容（如「隐藏了字段：GPS 定位」「调整了分段顺序」） |

## 十二、与报告详情页的衔接

| 配置项 | 影响报告详情页的表现 |
|--------|---------------------|
| **分段顺序** | `PreVerifyDetail.tsx` 中 Panel 的渲染顺序 |
| **分段显示/隐藏** | 对应 Panel 是否渲染（`condition && <Panel>`） |
| **字段显示/隐藏** | Panel 内部各字段/表格列的渲染控制 |
| **样式主题** | CSS 变量 / Tailwind 配置切换（主色调、风险色、字体、间距、圆角） |
| **导出模板** | 导出按钮的可用格式、导出文件的样式与内容范围 |
| **锚点导航** | 右侧 `navCards` 的顺序与可见性同步跟随分段配置 |

> 模板配置生效后，**新进入件**生成的报告按新模板渲染；**历史已生成报告**为快照，不受模板变更影响。

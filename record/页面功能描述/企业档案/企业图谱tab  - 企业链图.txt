## 二、左侧：企业链图画布区域（核心可视化区）
### 1. 画布顶部工具栏（居中横向）
元素从左至右：
1. 画布标题/节点标识：`比亚迪股份有限公司`
2. 功能图标按钮：
    - 关闭图标 `×`：清空/重置画布
    - 刷新环形图标 `⟳`：刷新图谱数据
    - `时间水印` 开关 + 开关控件：开启/关闭图谱节点时间水印展示
    - 下载图标：导出图谱
> 交互：图标hover展示tooltip提示，点击执行对应画布操作

### 2. 图谱画布（可缩放、拖拽的关系拓扑图）
#### 画布元素通用规范
1. **节点卡片（矩形）**：不同业务分类使用固定底色区分，左侧文字为内容，部分节点末尾带 `(数字)`、`+` 标识可展开下级
    | 节点分类 | 底色 | 示例 |
    | ---- | ---- | ---- |
    | 核心主体 | 深蓝色 | 比亚迪股份有限公司 |
    | 高管/人员 | 浅紫色 | 高管 |
    | 对外投资 | 浅紫色 | 对外投资 |
    | 分支机构 | 浅紫色 | 分支机构 |
    | 法院公告 | 浅粉色 | 法院公告 |
    | 历史股东 | 浅绿色 | 历史股东 |
    | 疑似关系 | 浅橙色 | 疑似关系 |
    | 控股/合作企业 | 浅橙色 | 山东国金汽车制造 |
2. **连接线**：灰色实线，关联两个业务节点，表示业务从属/关联关系
3. **展开控件**：`+搜索(数字)` 折叠按钮，点击展开下级关联节点；`搜索(13)+` 节点折叠入口
4. 节点内支持多行文本，部分节点附带占比字段 `2.75%`、`100.00%`

## 四、设计标准（前端开发规范）
1. **色彩规范**
    - 主色：#1677ff（选中Tab、核心节点、链接文字）
    - 节点区分色：深蓝（主体）、浅紫（人员/投资/分支）、浅粉（司法）、浅绿（股东）、浅橙（疑似/合作企业）
    - 正文：#333；辅助备注文字：#999
2. **字体规范**
    - 导航Tab：常规字重
    - 图谱节点：常规字重，节点内多行展示
    - 底部备注：小号字体
3. **交互规范**
    1. Tab切换：路由/组件切换，加载对应模块数据
    2. 图谱画布：拖拽平移、滚轮缩放、节点点击详情、折叠按钮展开下级
    3. 筛选复选框：双向绑定，勾选后实时过滤图谱节点
    4. 所有图标hover：浮起tooltip说明
    5. 下载按钮：导出图谱图片 / Excel结构化数据
4. **数据兜底规范**
    - 数量超过阈值展示 `999+`
    - 数据为0时正常展示 `名称 0`
    - 图谱加载失败、无数据时，需要空白占位+空状态文案
5. **响应约定**
    当前截图为PC端左右固定布局；左右面板宽度支持拖拽分割调整

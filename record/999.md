# 统一前置约定（方案基础，不变）
1. 系统载体：模型管理平台，流水线可视化调度
2. 流水线拓扑
> 串行主线：原始业务数据 → 节点1特征工程 → 节点2 Block前置拦截 → 节点3 逻辑回归评分卡(BaseScore) → 节点4 Rule主线扣分规则 → 节点5 主线衍生预警
> 并行支线（同源输入、同步运行）：原始业务数据 → 支线节点 Alert独立预警引擎
3. 基础参数（模型训练完成，已固化上线）
智信分基准 BaseScore=600，Odds₀=1:19，PDO=50
分数区间
≥660 低风险｜600~659 中等风险｜500~599 偏高风险｜＜500 高风险

规则清单
【Block强拦截】
Block-001：是否失信被执行人 = 是

【主线Rule扣分规则】
Rule-002：dir_ratio(定向贷款余额占比)＞70%  -50
Rule-003：dti_ratio(负债收入比)＞80%        -50
Rule-005：query_6m(近6个月硬查询次数)＞15   -50
Rule-008：util_ratio(循环授信使用率)＞70%    -50

【支线Alert预警规则（独立运行，不改分数）】
Alert-L1-002：团伙欺诈关联标记=是 【一级紧急预警】
Alert-L3-012：手机号入网时长＜6个月 【三级关注预警】

4. 格式标准
第一层：【客户自然人原始底层业务数据】（姓名、证件、手机号、征信原始事实，未经任何指标加工）
第二层：节点1【特征工程输入=原始业务数据；输出=衍生加工指标dir_ratio/util_ratio/dti_ratio等】
第三层：后续每一个节点：输入、算法类型、参数来源、节点输出

# 配套文字（可放进PRD/评审文档）
整套流水线部署于模型管理平台，可视化链路完整区分**串行主线**与**并行支线Alert预警节点**：
1. 系统输入端接收**客户自然人原始业务数据（姓名、证件、征信原始借贷、逾期、收入、设备信息等未经加工事实字段）**；
2. 首个节点为特征工程，基于原始事实数据自动衍生各类比率、次数指标；
3. 后续主线、支线全部依赖特征工程输出数据集运算；
4. 所有评分权重、规则阈值、衍生指标计算公式均通过历史信贷样本训练确定，上线固化；
5. 平台支持逐节点探查：输入原始数据清单、中间计算结果、算法类型、输出内容，完整链路可审计追溯。

# 1. 框架以后怎么用、怎么形容
你以后直接说这两种都行：

"调用统一框架实现 XX 功能"
"用框架做个 XX 的列表+详情"
我理解成一句话：列表 → 详情 → 返回 + 业务流程关联 的统一导航框架。

进详情自动记"你从哪个页面、哪个子系统来的"
返回自动落回那个页面
管理中心的业务流程（预警处置流程、贷前审核等）配置好自动挂到对应页面，改一处全站跟着变
四、约定确认
收到，以后你直接说"调用框架"，我默认就按这套（列表→详情→返回 + 业务流程关联）来做，不再重复交代返回逻辑。

dev server 还在 http://localhost:5174 跑着，改名和返回效果可以直接点进去看。

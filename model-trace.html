1先确立模式：1 + 1 = 2

任何模型都遵守同一个账本：原始数据 + 算法 = 输出。先把最简单的摆清楚，后面只是把「1」换成真实字段、「加」换成真实查表。

这一步的数据（Data）这一步的算法（Algorithm）输出（Output）
原始数据 A = 1取数1
原始数据 B = 1取数1
A、B 两个值加（ADD）：A + B2

记住这个账本格式：下面每一个因子都长这样——「原始数据 → 算法(查哪一行) → 加几分」。

2智信分（信用评分卡）全链路推演

2.2 分箱 → 计分表（这些加分是「算出来」的，不是随手给的）

某箱加分 = 缩放系数(本卡 12) × β(因子系数·训练得到) × WOE(箱的坏好证据·示意)

这是之前模型里缺的东西。下面把「算法本体」直接写进表：每一行原本是「某原始值 → 加几分」的硬规则；现在补上它背后怎么算的——WOE（这个箱好人多还是坏人多）和 β（模型系数）相乘再乘缩放，得到这一行的加分。β 和 WOE 是模型在带标签历史样本上训练拟合的，不是人给的；缩放系数（本卡 12）不是训练的——它是设计师按「基准分 600 + PDO（好客户概率翻倍所需点数）」定的业务校准常数，见 2.2.2。

2.2.1 那 +30 / −48 到底是怎么「算」出来的？（大白话）

模型看不懂「逾期 1 次」这种话，它只认数字。所以把一个原始值变成「加几分」，分三小步：

  • 第一步 · 分箱：把「逾期 1 次」归到「1 次」这个箱里（和 2.2 左边区间一致）。
  • 第二步 · 算这个箱的「好坏分」(WOE)：看这个箱里历史上有多少人按时还钱（好人）、多少人赖账（坏人），压成一个数字：
    WOE = ln( 好人的比例 ÷ 坏人的比例 )。 好人越多 → 数字越大（越该加分）；坏人越多 → 数字越小甚至变负（越该减分）。
  • 第三步 · ×系数变成「分」：模型对每个因子，在带标签的历史样本上训练拟合出一个系数 β（智信用逻辑回归、智察用 XGBoost 叶子权重；本质都是「从数据算出来的」，不是人拍的）。最终这个箱贡献的「分」= 缩放系数 × β × WOE。 2.2 表里那些 +30 / −48，就是这一步算出来的结果——你也能在 2.2 的表里看到每一行都写了 12 × β × WOE。

一句话：模型把「逾期 1 次的人大多是好人」这个直觉，量化成了一个数字（+30）。不是谁拍的。

6智察分（XGBoost 反欺诈）全链路推演

6.2 XGBoost 怎么算（用示意树带你走一遍）

XGBoost = 很多棵决策树加起来。每棵树：特征走分叉到某个叶子，叶子有个「权重」（leaf weight）。所有树的叶子权重求和 = logit，再过 sigmoid 变成好客户概率 p，智察分 = p × 100。

叶子权重 = 智信里的 β×WOE：在 XGBoost 里，每个叶子的权重扮演的正是「系数×证据」的角色——而且它是模型从带标签历史样本上梯度提升训练出来的，真算出来的（不是业务拍的）。只是 demo 没有真实训好的树，下面用示意权重让你看清整条链路、能照算验证。

下面用 4 棵示意树走样例客户（3 / 低 / 2 / 58% / 未命中黑灰）：

树分裂条件 / 客户走哪边叶子权重
T1申贷平台数 ≤ 3？是（3）→ 左叶+0.6
T2设备风险 = 低？是 → 左叶+0.4
T3负债比 ≤ 60%？是（58）→ 左叶+0.3
T4关联账号 ≤ 2？是（2）→ 左叶+0.2
叶子权重求和 = logit+1.5
p = sigmoid(1.5) = 1 / (1 + e^(−1.5)) = 1 / (1 + 0.2231) = 0.8176
智察分 = 0.8176 × 100 = 81.8 ≈ 82（与决策图 zhicha「当前样本 82」一致 ✓）

若命中黑灰名单：不管树算多少，直接封顶 95（拒绝）——这是硬拦截，覆盖模型分。所以「黑灰名单命中」本身是一条碰撞/覆盖规则（见 6.3 的 za-1）。
